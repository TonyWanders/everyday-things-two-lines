# A Queue Is a Caterpillar

A program that writes one two-line explanation of a queue to `/output/entry.txt`,
for the make.fun competition
[Everyday Things, Two Lines, Longer Run](https://make.fun/bounty/u-suga-everyday-things-two-lines-longer-run-f8734479).

Run it with Python 3:

```
python3 main.py
```

It writes the entry below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The entry is 382 characters in 2 lines, inside the 1 to 400 gate.

## The entry

```
A queue is a line of people waiting their turn, like a caterpillar that crawls forward one small wiggle each time the shop lets the person at its head go in.
The caterpillar fits because a queue really does move in small steps from the front, one person at a time, but it leaves out that the people can chat, get bored, or walk away, while a caterpillar never chooses where it goes.
```
